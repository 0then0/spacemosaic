# Code of conduct

Discuss technical decisions with evidence and respect. Participation is open
regardless of experience, language, origin, age, gender, or disability.
Harassment, threats, discriminatory remarks, sexual harassment, and publishing
another person's private information without consent are not acceptable.

This policy applies to repository issues, pull requests, discussions, and other
project spaces. Maintainers may remove harmful content, close discussions, or
restrict participation according to severity and repeated behavior.

Report a concern through the repository owner's available GitHub profile
contact. Do not post private evidence in a public issue. The project does not
yet operate a dedicated confidential conduct-reporting address.
